LESSON 01The language

Start with the big idea

What is Python?

Python is a programming language: a way to write instructions that a computer can understand and carry out. It is known for readable code, which makes it a good first language for learning how programs work.

Think of it this way: you give the computer precise steps; Python gives those steps a written form. The computer follows them in order, one instruction at a time.
01 · Instructions

Be precise

A computer follows the steps you write, so each instruction needs a clear purpose.

02 · Order

One step at a time

Python reads your program from top to bottom unless you tell it to choose or repeat.

03 · Meaning

Use the rules

Python has its own grammar. A small spelling or punctuation change can matter.

Our first instruction
# Ask Python to show a message print("Hello, Python!") # Output Hello, Python!

print() is a built-in Python function. It displays the value you place inside its parentheses. The quotation marks tell Python that Hello, Python! is text.

LESSON 02A conversation

Input goes in; output comes out

Input and output

Programs become useful when they can receive information and respond. Input is information given to a program. Output is what the program returns, displays, or produces.

In Python: input() pauses and waits for a person to type. print() displays a result. Together, they make a simple conversation.
The Python program
# Receive a name as text
name = input("What is your name? ")

# Send a greeting back
print("Welcome, " + name + "!")
Try it · live example
Program output
Welcome, Python learner!
↳ Change the name above. The output updates as you type.

Read it carefully: the computer waits at input(). The typed answer is stored in the variable name. Then print() combines the greeting and the name, and displays the result. The live box above models that input-and-output cycle.

A useful detail: input() gives you text, even if someone types digits. To do arithmetic, convert it first: age = int(input("Age: ")). Here int() turns the text into a whole number.
